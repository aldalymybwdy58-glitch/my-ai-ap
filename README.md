🤖 my-ai-ap

تطبيق ذكاء اصطناعي عربي حديث

my-ai-ap هو تطبيق ذكاء اصطناعي مصمم لمساعدة المستخدمين على الإجابة عن الأسئلة، إجراء المحادثات، وإنجاز المهام بسهولة من خلال واجهة حديثة وبسيطة.

✨ المميزات

- 💬 محادثة مع الذكاء الاصطناعي
- 🌐 دعم اللغة العربية
- 📱 تصميم مناسب للهواتف
- 🎨 واجهة حديثة مستوحاة من تطبيقات الذكاء الاصطناعي الحديثة
- 📎 إمكانية إضافة الملفات
- 🎙️ دعم الإدخال الصوتي
- 🗂️ محادثات جديدة وسجل للمحادثات
- ⚡ استجابة سريعة وبسيطة

🛠️ التقنيات

- HTML
- CSS
- JavaScript
- Cloudflare Workers
- OpenAI API
- GitHub

📁 ملفات المشروع

- "index.html" — واجهة التطبيق.
- "_worker.js" — خادم التطبيق وربط واجهة المستخدم بالذكاء الاصطناعي.
- "wrangler.json" — إعدادات نشر Cloudflare.
- "README.md" — معلومات ووصف المشروع.

🚀 الهدف

إنشاء مساعد ذكاء اصطناعي عربي سهل الاستخدام، بواجهة نظيفة وحديثة وتجربة قريبة من تطبيقات المحادثة بالذكاء الاصطناعي.
